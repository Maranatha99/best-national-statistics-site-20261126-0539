ARUNIKA — Indonesia dalam Angka: a national statistics site for Indonesia, built entirely from static files with no network requests. It covers population (all 38 provinces, searchable, sortable and filterable), the economy (GDP growth 2019–2024, nominal GDP, sector shares), employment and poverty, foreign trade (exports vs imports 2019–2024, per-year detail), and development (HDI, inflation, Gini). Every figure comes from Badan Pusat Statistik (BPS) with its source and year shown. Charts are hand-built SVG from the site's own data; the layout works on desktop (1280×800) and on a phone (390×844).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
